# Day 3 — Computer basics: memory, storage and data units (CUET PG LLB)

## Lesson

**Why this matters.** The CUET PG general paper (DU LLB) has a computer-basics unit. These are the cheapest marks
in the paper: pure recall, ~20 seconds each, +4 apiece. But at −1 per wrong answer, a half-remembered fact costs you.
Today: the memory family, the speed ladder, and the units.

**1. The CPU and memory.** The CPU = ALU (arithmetic and logic) + CU (control unit) + registers.
Memory splits in two:
- **Primary memory** — directly accessed by the CPU: **RAM** (Random Access Memory; read/write, **volatile** — loses
  data when power goes) and **ROM** (Read-Only Memory; **non-volatile**). Cache memory and registers also sit here.
- **Secondary memory** — stores data permanently, non-volatile: HDD, SSD, pen drive, memory card, CD/DVD, magnetic tape.

**ROM family (expansions are a favourite):** PROM = Programmable ROM (written once) · EPROM = Erasable PROM (erased with
UV light) · EEPROM = Electrically Erasable PROM (erased electrically; flash memory is a type of it).
**BIOS** (Basic Input/Output System) — the start-up firmware — is stored in ROM (on modern boards, flash/EEPROM chips; exam answer: ROM).

**2. The speed ladder (fastest → slowest, smallest → largest, costliest → cheapest per byte):**
**Registers → Cache → RAM (main memory) → SSD/HDD → optical disc/tape.**
Mnemonic: *"Real Champions Run Steadily, Taking Time."*

**3. Units (CUET uses the binary convention unless the question says otherwise).**
bit → **nibble = 4 bits** → **byte = 8 bits** → KB = 1024 bytes → MB = 1024 KB → GB = 1024 MB → TB = 1024 GB → PB = 1024 TB.
Method: each step up is ×1024 (= 2¹⁰). To convert down, multiply by 1024 per step; up, divide.

**Worked example (CUET style).**
*How many KB are there in 3 MB?* — one step down → 3 × 1024 = **3,072 KB**. The trap option will be 3,000.

**The traps examiners set.**
- "ROM is volatile" / "cache is secondary memory" — both false. Cache is *primary*, between registers and RAM.
- Swapping registers and cache in the speed order. Registers sit *inside* the CPU and are the fastest.
- 1000 instead of 1024 in unit conversions.
- EPROM vs EEPROM: UV light vs electrical erasure.

## Test — 8 questions, ~10 minutes (72 s each), +4 / −1

**1.** Which of the following memories loses its contents when the power supply is switched off?
- (A) ROM
- (B) Hard disk drive
- (C) RAM
- (D) Flash drive

**2.** Which option arranges the memories correctly from **fastest to slowest**?
- (A) Cache > Registers > RAM > Hard disk
- (B) RAM > Cache > Registers > Hard disk
- (C) Registers > RAM > Cache > Hard disk
- (D) Registers > Cache > RAM > Hard disk

**3.** A group of 4 bits is called a:
- (A) Nibble
- (B) Byte
- (C) Word
- (D) Kilobit

**4.** How many kilobytes make up 2 megabytes?
- (A) 1,024
- (B) 2,000
- (C) 2,048
- (D) 20,480

**5.** The BIOS, which starts the computer when it is switched on, is stored in:
- (A) RAM
- (B) ROM
- (C) Cache memory
- (D) Registers

**6.** Which of the following is **not** a secondary storage device?
- (A) Cache memory
- (B) Solid state drive
- (C) Pen drive
- (D) DVD

**7.** EEPROM stands for:
- (A) Extended Erasable Programmable Read-Only Memory
- (B) Electrically Erasable Programmable Read-Only Memory
- (C) Electronically Encoded Programmable Read-Only Memory
- (D) Erasable Electric Permanent Read-Only Memory

**8.** Under the Indian Contract Act, 1872, a proposal may be revoked at any time before the acceptance is complete as
against the proposer (i.e. when the acceptance is put in the course of transmission), and a revocation is complete as
against the person to whom it is made only when it comes to his knowledge. Arun posts an offer to Babita. On 9 March
Arun posts a letter of revocation. On 10 March Babita posts her acceptance. The revocation reaches Babita on 11 March;
her acceptance reaches Arun on 13 March. Which statement is correct?
- (A) No contract: Arun posted his revocation on 9 March, before Babita posted her acceptance.
- (B) No contract: the revocation reached Babita before her acceptance reached Arun.
- (C) No contract: a proposer may revoke at any time until the acceptance reaches him.
- (D) A contract was formed: the revocation reached Babita only after she had posted her acceptance.
